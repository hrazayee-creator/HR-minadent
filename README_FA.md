# سامانه منابع انسانی MINADENT HR

این بسته یک نسخه وب دارای API و پایگاه داده مشترک است. رابط فارسی داخل `app/static/index.html` قرار دارد و FastAPI آن را به همراه API ارائه می‌کند.

## استقرار پیشنهادی (Render)
1. فایل ZIP را از حالت فشرده خارج کنید.
2. کل محتویات پوشه `MINADENT_HR` را در یک مخزن GitHub بارگذاری کنید (محتویات پوشه، نه خود ZIP).
3. در Render یک Blueprint جدید بسازید و مخزن را متصل کنید؛ Render تنظیمات `render.yaml` را می‌خواند.
4. هنگام ایجاد سرویس، برای `ADMIN_PASSWORD` یک رمز قوی و حداقل ۸ نویسه تعیین کنید.
5. پس از Deploy، لینک سرویس Render را باز کنید و با `admin` و رمزی که خودتان تعیین کردید وارد شوید.

## اجرای آزمایشی روی رایانه
Python 3.11 یا جدیدتر نصب باشد:
```bash
pip install -r requirements.txt
ADMIN_PASSWORD='A-Strong-Password-123' uvicorn app.main:app --reload
```
سپس `http://127.0.0.1:8000` را باز کنید.

## امکانات موجود
- ورود با نقش مدیر اصلی و حساب واحد
- تفکیک مشاهده و ثبت اطلاعات بر اساس واحد
- پرونده پایه پرسنل و کد پرسنلی یکتا
- ثبت درخواست مرخصی روزانه و ساعتی، پیوست فایل تا ۲ مگابایت، تأیید و رد
- ثبت دیرکرد و اضافه‌کار
- تبدیل مجموع دیرکرد به روز و دقیقه باقی‌مانده؛ مقدار اولیه ۵۴۰ دقیقه و قابل تنظیم
- داشبورد و شمارش پرسنل به تفکیک واحد
- ساخت حساب مدیر و حساب واحد
- پشتیبان‌گیری و بازیابی JSON
